Product brief

Problem

Portfolio analysts answer the same exposure and risk questions many times a day by pulling numbers from several screens. General-purpose chatbots can phrase those answers well but may invent figures, which is unacceptable in a regulated investment workflow.

Target user

A portfolio or risk analyst who needs quick, defensible answers about one portfolio's holdings, limits, and scenario impact, and who must be able to show where each number came from.

Approach

  • The model never sees raw prices and never does arithmetic. It calls deterministic tools (summary, holdings, exposures, limit check, stress test) and writes the answer from their results.
  • Each answer lists the tools it called and their arguments, so a reviewer can reproduce it.
  • Questions outside the data, such as price forecasts or buy/sell calls, are declined and redirected.

Success metrics

  • Grounding rate: share of numbers in answers that match a tool output exactly. Target 100%.
  • Tool-selection accuracy on the eval set below. Target 90% or higher.
  • Time to answer a routine exposure question versus manual lookup.
  • Guardrail pass rate on out-of-scope prompts. Target 100%.

Risks and mitigations

  • Hallucinated figures: tools return all numbers, and the prompt forbids stating any figure not in a tool result.
  • Over-trust in a simple model: the stress test is a linear beta and duration approximation, labeled as such in the interface.
  • Advice-seeking prompts: refused with a pointer to what the tools can answer.

What's next

  • Multi-portfolio comparison and benchmark-relative exposures.
  • Automated scoring of the eval set on every prompt change.
  • Export of an answer and its tool trace into a compliance log.
